# 01 总体设计思路

## 1. 任务

前哨站和基地各有一盏**绿色圆形引导灯**，7 分钟比赛阶段内常亮。
前哨站目标固定；基地目标在开闸、飞镖发出后离散换位置（±280mm，600ms 内停稳），
不是持续摆动。

视觉需要做的：

1. 同时识别画面里的所有引导灯；
2. 两灯以上同时可见时，取面积最大的两个，再按左右分身份：左 = 前哨站，右 = 基地；
3. 根据串口下发的目标选择，把飞镖架粗对准选中目标；
4. 对准后进入 HOLD，保持云台不动，基地后续的随机移动交给制导镖。

发射和弹道解算全部不需要；不需要 PnP、世界坐标或云台角度。

## 2. 核心判断：为什么只需要 X 坐标（不需要 PnP / 世界坐标 / 手眼标定）

相机刚性安装在飞镖架上，随飞镖架一起在水平方向转动，光轴大致与发射方向一致。

> 关键：**让目标在画面里居中 = 让飞镖架正对目标。**

因此这是一个纯**图像伺服（IBVS）**问题，只需要目标的像素 X 与图像中心的水平偏差：

```
水平误差(像素)   = target_x - cx
水平角度(rad)    = atan2(target_x - cx, fx)
```

其中 `fx`、`cx` 是相机内参（棋盘格标定得到）。

- 不需要 PnP：PnP 是解"目标在 3D 空间的位置/姿态"，而这里只要水平方向角；
- 不需要世界坐标系：世界坐标依赖 IMU 四元数（已经去掉），而且对"转正对"没有帮助；
- 不需要手眼标定（`R_camera2gimbal` / `t_camera2gimbal`）：那是把相机坐标转到云台坐标用的，只有做 3D 解算时才需要。

结论：**相机内参标定还是要做**（得到 fx、cx），但**手眼标定和 PnP 可以不做**，反而少了误差来源。

> 你提到"相机在飞镖架上转动、高度不变，可能在世界坐标系下会更好"——对于"转正对"这个目标，世界坐标系不会更好，只会引入 IMU 噪声和标定误差。放心去掉。

## 3. 关键点：多目标 + 粗对准一次

2027 规则下基地目标**不是持续摆动**，而是"静止 → 事件触发换位置（600ms 内停稳）→ 静止"。
所以底座不需要持续追踪，只需要：

1. 两灯以上同时可见时，取**面积最大的两个**，再按左右分身份：左 = 前哨站，右 = 基地；
2. 根据串口命令选择本次要打的目标（`1` = 前哨站，`2` = 基地）；
3. 云台转向选中目标，误差进入阈值并连续 N 帧后进入 **HOLD**；
4. HOLD 后不再输出角度（`target_yaw_deg = 0`），电控保持云台不动，
   目标后续的随机移动交给**制导镖**；
5. 需要重新对准时，电控发 `command = 3`。

云台纯 yaw 转动不改变左右顺序，所以这个方案不需要 PnP、世界坐标或云台角度。
原来的"周期窗口极值中点"只适用于旧测试台架的周期摆动，已经移除。

## 4. 数据流

```
海康相机线程 ──CameraFrame──▶ SPSCQueue ──▶ 飞镖处理线程
                                                │
                                    1. DartDetector::detectAll 检测所有引导灯
                                    2. DartTrack 左右分身份 + 粗对准/HOLD
                                                │
                      串口线程 ◀── sendDart(found, target, state, target_yaw_deg)
                                                │
                        电控（转向选中目标；state=2 时保持云台不动）
```

## 5. 与原自瞄代码的对应关系

| 原自瞄模块 | 飞镖模块 | 说明 |
| --- | --- | --- |
| `armor_detector`（灯条+数字识别） | `dart_detector`（多目标绿色灯检测） | 颜色+形状，无深度学习模型 |
| `armor_track`（EKF 追踪） | `dart_track`（目标选择 + 粗对准锁定） | 无 EKF，只做左右分身份和 HOLD |
| `armor_pose`（PnP+手眼） | （删除） | 只需内参 fx/cx |
| `armor_shoot`（弹道+开火） | （删除） | 无发射 |
| 串口接收 IMU 四元数 | （删除） | 发送 + 接收目标选择命令 |
| `hikcamera` / `serial` 底层 | 原样保留 | 通用部分 |
