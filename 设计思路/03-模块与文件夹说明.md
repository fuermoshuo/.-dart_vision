## 各模块职责

| 模块 | 职责 | 输入 | 输出 |
| --- | --- | --- | --- |
| `hikcamera` | 驱动海康相机取流、断线重连、丢帧统计 | MVS SDK | `CameraFrame` |
| `hikcamera_thread` | 循环取帧并 `try_push` 进 SPSCQueue | `CameraFrame` | 队列 |
| `dart_detector` | HSV 绿色阈值 → 形态学 → 轮廓/白核过滤，输出所有引导灯 | BGR 图像 | `vector<DartTarget>`（按 x 排序） |
| `dart_track` | 左右分前哨站/基地，粗对准后锁定（HOLD） | `vector<DartTarget>` + 串口命令 | `DartAimResult`（target/state/found/target_yaw） |
| `dart_thread` | 串联检测 → 目标选择/粗对准 → 发送 | 图像队列 | `sendDart(...)` |
| `serial` / `serial_thread` | 串口收发、断线重连 | 串口字节流 | 发送包给电控 |
| `display` | SDL2 窗口显示检测结果（调试） | 图像 + 叠加图形 | 屏幕窗口 |
