# Dart Vision —— 飞镖视觉识别模块

基于队伍自瞄代码（`liu` 文件夹）改造的**飞镖靶目标识别模块**。

- 保留：海康相机驱动（`hardware/hikcamera`）、串口通信（`hardware/serial`，去掉了 IMU 四元数接收）。
- 替换：装甲板检测 → **绿色圆形目标检测**（`dart_aim/dart_detector`）。
- 新增：多目标选择 + 粗瞄准锁定（`dart_aim/dart_track`）。
- 删除：发射/弹道解算、PnP、世界坐标系、手眼标定、EKF 追踪、数字识别模型、USB 相机、ROS2。

新规则下前哨站/基地各有一盏绿色引导灯，比赛阶段内常亮。视觉同时识别所有引导灯，
先取**面积最大的两个**，再按左右分身份（左 = 前哨站、右 = 基地）；
根据串口目标选择把云台粗对准选中目标，误差收敛后进入 **HOLD** 保持不动，
基地后续的随机移动交给制导镖。

## 快速开始

```bash
# 1. 安装依赖（见 设计思路/02）
# 2. 编译
mkdir build && cd build
cmake .. && make -j8

# 3. 运行（相机 / 串口 / 识别自动启动）
./dart_vision

# 没有相机时：用视频离线验证（见 设计思路/06）
cmake .. -DDART_VISION_OFFLINE=ON && make -j8 dart_video_test
./dart_video_test test.mp4 --save out.mp4
```

调试时把 `config/dart_vision.yaml` 里的 `detector.debug` / `track.debug` 设为 `true` 可打开可视化窗口。
